## Keyboard reactions don't work / 键盘没反应 / キーボードに反応しない

Open System Settings › Privacy & Security › Input Monitoring and turn on Typing Chicken, then quit and reopen the app.

打开“系统设置 › 隐私与安全性 › 输入监控”，打开打字鸡，然后退出并重新打开 app。

「システム設定 › プライバシーとセキュリティ › 入力監視」でタイピングチキンをオンにし、アプリを終了してから開き直してください。
